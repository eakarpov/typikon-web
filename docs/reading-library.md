# Библиотека для вдумчивого чтения

Сценарии первого выпуска равноправны: последовательное чтение книги и работа над вопросом. Веб: `/study`, входы из `/library` и читателя; приложение: «Библиотека», прежний каталог доступен по `/library/catalog`.

## Данные и совместимость

Общий API `/api/v2/study`: `catalog`, `material`, `related`, `routes`, `package`, `personal`, `change`, `publish`, `shared`, `plan`. Публичное чтение использует существующий scope `texts`; личные операции дополнительно требуют сессию пользователя. Список материалов не дублируется в приложении.

Адрес хранит вид источника, постоянный ID, конкретное издание, каноническую главу/стихи либо статии, ID исходного блока, цитату, контекст и номер вхождения. Диапазон хранит оба конца. Отпечаток относится к исходному тексту. Начертание и ударения не являются редакцией. FNV служит обнаружению изменений, а не криптографическим подтверждением источника; неоднозначная цитата автоматически не переносится. Ключи дискового кэша — SHA-256.

Старые заметки и подборки читаются из `userNotes` и `readingCollections` с прежними ID. Неразрешённая старая привязка остаётся видимой; уточняется явным действием. При уточнении сохраняются первоначальные цитата и адрес. Старые позиции открываются прежним читателем, без выдумывания точного адреса из процента прокрутки. Новый библиотечный сценарий сохраняет последнее место и после 95%; статус «Прочитано» выставляет человек.

Новые личные позиции и связи отделены от молитвенных отметок. Для подборки сохраняется собственная позиция, включая конкретное повторное вхождение источника. Книга также имеет отдельное место и явный статус: её главы читаются подряд через «Предыдущий/следующий материал» и общее оглавление; продолжение восстанавливает книгу и главу, в том числе без сети. Повтор операции с opId не создаёт дубликат; состав и записи меняются по версии. Конфликт сохраняет локальную и серверную версии. Подборка подключается к существующему личному плану только после явного предпросмотра; повтор создания не сбрасывает указатель и не заменяет другой план.

## Редакционные материалы

В `src/data/study` находятся три маршрута: «О молитве» (7 отрывков), «Покаяние и возвращение» (6), «Пасха в Писании и богослужении» (8). Проверены буквальные отрывки текущего доступного корпуса, издания, диапазоны Писания и адреса. Статус checked описывает эту сверку; это не церковное одобрение и не заявление о внешней научной экспертизе.

Покрытие: Лествица, Пролог о Марии Египетской, синаксари Постной и Цветной Триоди, огласительное слово на Пасху, беседы Златоуста на Иоанна и Матфея, Толковый апостол, три песнопения и Елизаветинская Библия. Привязки собственно толкований: Ин 1:1 (слово второе), Мф 4:1 (беседа 13), Деян 1:2–3. Цитата Рим 2:13 в вводной беседе на Бытие обозначена как цитирование. Единственная наполненная вводная беседа не выдаётся за покрытие всех глав Бытия.

Всего 22 проверенные связи: 3 толкования, 1 цитирование, 18 тематических переходов. Каждая содержит автора разметки, основание, точное место, адрес источника, версию и дату сверки. Святоотеческие монашеские наставления сохраняют указание на свой контекст. Никаких толкований при чтении не генерируется.

Автоматические кандидаты импортируются в `studyRelations` через `src/scripts/study-relations-import.ts`; по умолчанию status=candidate и публичная выдача их исключает. `--checked` требует STUDY_REVIEWER и проверяет точные адреса. Редактор предварительно проверяет смысл связи: совпадение слов само по себе не является основанием. Подтверждённые соответствия редакций можно открыть рядом на широком экране либо переключать на телефоне; без соответствия используются самостоятельные оглавления. Начальный корпус не содержит вновь придуманных параллелей редакций.

## Офлайн и приватность

Скачиваются выбранные тексты целиком с контекстом, метаданными и сносками, плюс справки связей. Тексты по связям не скачиваются рекурсивно: их можно сохранить явно. Большие книги загружаются порциями. Показываются объём, сохранённые источники и недостающее; отсутствие текста/сноски исключает полноту копии. Русский перевод не подменяется объяснением смысла.

Гостевые записи локальны. После входа перенос предлагается явно и не заменяет существующие записи. Кэши и очереди привязаны к владельцу; выход очищает личные кэши текстов и полностью синхронизированные копии, блокирует поздние записи старых запросов. Личная копия с незавершёнными операциями или конфликтами сохраняется в пространстве прежнего аккаунта и открывается только после повторного входа в него. Публичная оболочка страницы не содержит личных записей. Явный отказ API в доступе не подменяется старым кэшем; при отсутствии сети доступна сохранённая копия.

Публикация создаёт независимый снимок и показывает его состав. По умолчанию заметки и вопросы исключены; включаются по одному явным выбором. Проверяется владелец записи и доступность её источника. Скрытие источника закрывает его материал и в старой опубликованной копии. Markdown и JSON сохраняют собственные записи и адреса, включая исходную выписку при уточнении места.

## Проверка

Модельные и интерфейсные тесты мобильного читателя: второй повтор цитаты, исходный адрес после смены начертания, диапазоны, вопросы без молитвенных отметок, холодное офлайн-открытие, поздний ответ после смены аккаунта, конфликты. Веб-интеграционные проверки выполняются на изолированной MongoDB 127.0.0.1:27129 с общедоступными текстами и искусственными пользователями: повтор операции, версии, изоляция владельцев, старые ID, безопасная публикация, недоступный источник, повтор создания плана без сброса позиции.

Для локального стенда `scripts/tests/study-seed.cjs` требует `STUDY_FIXTURES_DIR` с общедоступными выгрузками `study-corpus.json`, `study-bible.json`. Скрипты тестов имеют фиксированные localhost-адреса и не создают пользователей в production. Выгрузки не включают личные данные и не входят в Git.

Публичный Android остаётся прежним. Новый APK предназначен для личной приёмки владельцем; обновление эндпойнтов версии и публичного каталога APK требует отдельного указания.
