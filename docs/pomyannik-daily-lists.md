# Группы, возраст и дневные порции

Импорт использует существующее поле `groups` каждого добавляемого лица. По умолчанию передаётся пустой массив; выбранная в приложении группа применяется ко всем пачкам импорта.

`DELETE /api/v2/pomyannik/groups` принимает `{id, deletePersons}`. При `false` удаляется только одна связь с группой; остальные группы и имена сохраняются. При `true` действующие лица группы перемещаются в корзину, в том числе входящие в другие группы. Чужие учётные записи не затрагиваются. Настройки поминовения удалённой группы выключаются, соответствующая закладка очищается.

Возрастные пометы вычисляются при выводе: до 7 лет — младенец, от 7 до 14 — отрок/отроковица по полу, с 14 лет возрастной пометы нет. Для усопших используется день преставления, поэтому возрастная помета не меняется с течением времени. Без полных дат ручная помета сохраняется с проверкой пола. Полные даты нужны для точных границ возраста; порядок рождения и преставления проверяется также при указании только года. Прочие выбранные чины сохраняются.

Настройка каждого места поминовения может содержать `daily: {size: 10, start: "2026-11-14"}`. Отсутствие `daily` означает полный список. После фильтрации раздела/группы и исключения корзины берётся циклическое окно размера `min(size, list.length)`, смещённое на `elapsedDays * size`. Для 15 имён: 1–10; 11–15 и 1–5; 6–15. Одно имя не повторяется внутри дня. День общий для устройств, по Москве. Изменение размера в приложении начинает новый цикл с сегодняшнего дня.

Поддерживаются славы Псалтири, утренние и дополнительные вечерние поминовения. Вечерние по умолчанию выключены. Снимки ответа содержат день: вчерашние плавающие порции не показываются при отсутствии сети.

Лидия добавлена как отдельное личное имя по https://azbyka.ru/days/sv-lidija-illirijskaja с женской парадигмой N3e. Географическая лексема Лидии не подменяет личное имя.
