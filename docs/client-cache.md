# Автоматическое обновление HTTP-кэша

Приложение 2.3.2+12 и портал 1.2.4.

Публичный `GET /api/cache-version` возвращает `{ "version": "<sha256>" }`
с `Cache-Control: no-store`. Маркер включает `.next/BUILD_ID`, размер, mtime и ctime
файла `RULES_DB`. Новый портал или замена корпуса меняют маркер. При отсутствии
сборки/корпуса ответ 503 без деталей: недоступность не считается новой версией.
Проверка не использует Mongo, сессию или ключ API. Для внепланового обновления
данных в Mongo можно изменить `CLIENT_CACHE_REVISION` и перезапустить сайт.
Штатная выкладка портала автоматически меняет BUILD_ID, выкладка корпуса
заменяет файл и перезапускает процессы, читающие его.

Приложение сохраняет поколение `appVersion + serverVersion + localEpoch`
в каждом HTTP-ответе. Проверка при запуске, возврате в приложение и каждые
пять минут на переднем плане; одновременные запросы разделяют одну проверку.
У старого сервера (404) временно читается buildId из `/api/health`.

Смена поколения или старый файл без поколения требуют загрузки свежего ответа
перед показом. При недоступной сети, исключении или 5xx сохранённое чтение
остаётся доступно; его дата и поколение не продлеваются. 4xx возвращается
вызывающему без подмены старым успешным ответом. Негодные ответы не сохраняются.
Внутри одного поколения остаётся прежний TTL и фоновое обновление.
Начатый до смены поколения запрос не может записаться в новое поколение.
Кнопка ручной очистки дополнительно меняет localEpoch.

Изменение маркера перезагружает открытые экраны выбранного дня. Открытое чтение
сохраняет позицию; свежие данные будут загружены при следующем открытии текста.
Настройки, закладки, авторизация, личный помянник и его офлайн-снимки не удаляются.
Устаревшие HTTP-снимки заменяются при успешной загрузке, оставаясь резервом
без сети. Дополнительные действия пользователя после обновления не нужны.

Проверки: Flutter `test/http_cache_version_test.dart`, сервер
`src/lib/cacheVersion.test.ts`. После выкладки проверить публичный endpoint
без ключа и наличие `Cache-Control: no-store`.
