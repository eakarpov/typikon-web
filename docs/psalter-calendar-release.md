# Псалтирь и восстановление полноты календаря

Версии: приложение 2.3.1+11, портал 1.2.3, корпус typikon-rules 1.0.1.

## Корпус

`rules/texts/psaltir-kafizmy.yaml` — версионируемый источник двадцати окончаний
кафизм и краткого поминовения. Источник текстов указан в самом файле:
https://azbyka.ru/molitvoslov/psaltir-po-kafizmam.html. Это церковнославянские
тропари и молитвы, без современного русского перевода. Редакционная формула
поминовения помечена отдельно; список имён в ней один.

Штатная сборка запускает `migrate_psalter_kelia` после Молитвослова.
Для уже собранной базы есть безопасное обновление её копии:

```sh
cd ../typikon-rules
python3 scripts/test_psalter_kelia.py
python3 scripts/update_psalter_corpus.py src/data.db /tmp/psalter-release.db
```

Исходная база не изменяется; скрипт проверяет целостность результата и
внешние ключи. В этой задаче проверенная обновлённая база уже установлена
в `typikon-rules/src/data.db`. Предыдущая копия: `/tmp/typikon-before-psalter.db`.
В корпус добавлено 225 вхождений, 20 отдельных молитв проверены через API-слой.

## API

- `GET /api/v2/posledovanie?key=psaltir-kafizma-N&lang=cu`, N=1..20.
  При отсутствии уставного слоя ответ честно указывает `lang=cu_gr`.
  Порядок: Трисвятое по Отче наш, свои тропари, Господи помилуй (40), своя молитва.
- `GET /api/v2/prayer-text?for=departed&style=psalter-departed&lang=cu&gender=m`.
  Личный ответ с именами из помянника; родственные категории не подставляются.
- `/api/v2/calendar/{date}/saints` объединяет Днеслов и свой каталог.
  Поля `partial` и `sourceStale` описывают полноту. Дневные ответы, имена и
  карточки источника сохраняются в `dneslov_http_cache`; внешние памяти
  пополняют `dneslov_memories`. Снимки и ручные сведения `saints` разделены.
  Синхронизация `npm run dneslov:sync -- --write` подбирает новые частичные
  записи дневного кэша; `npm run saints:build -- --write` затем расширяет
  собственный каталог. Их можно выполнять отдельно от выкладки, с выбранными
  ограничениями нагрузки. Одна ручная связка больше не требуется для показа памяти.

## Выкладка

1. В выбранном профиле выкладки доставить обновлённый корпус:
   `npm run release:rules-db`.
2. Выложить портал 1.2.3: `npm run release`.
3. Проверить публичные окончания 1-й, 17-й и 20-й кафизм; личную молитву
   проверить из вошедшего аккаунта, убедившись, что каждое имя вставлено один раз.
4. Проверить календарь обычного дня и Пасхи, успешный повтор из кэша при
   недоступности Днеслова и открытие памяти, которой ещё нет в ручных связках.
5. После сервера распространить приложение 2.3.1+11. Оно сбрасывает прежние
   многолетние снимки неполных дней и старые снимки персональных молитв.

Установочные проверки: китайское и грузинское издания Библии доступны в
выборе; недостающие знаки отрисовывает системный font fallback. Встроенные
Monomakh и OldStandard сами этих письменностей не содержат.

Продакшен из этой задачи не обновлялся. В рабочем дереве портала до задачи
уже были изменения других направлений; перед выкладкой нужно проверить
полный набор изменений, попадающий в релиз.
