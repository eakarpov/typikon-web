## Данные и резервная копия

Перед изменениями сохранены MongoDB `typikon` и SQLite; перед выкладкой новостей —
`typikon-news`. Mongo-архивы проверены через `mongorestore --dryRun`.
Каталог резервной копии на сервере:
`/var/www/typikon.su/typikon-web-releases/backups/6.4-20261031T104946Z`.
Файлы окружения в резервную копию не включались.

`typikon` перенесена штатным скриптом по пяти частям, все восстановления без ошибок.
Ключевые коллекции сверены с локальной базой по числу записей и SHA-256:
7 986 текстов, 50 книг, 759 дней, 73 седмицы, 1 079 зачал.
SQLite также совпадает по SHA-256; после подключения пересчитан свод цитируемости.
База `typikon-users` этой выкладкой не заменялась.

В коллекции новостей 50 публикаций. Прежние 49 сохранены, включая исходные ID;
отсутствовавшая локально новость 6.3 восстановлена перед окончательным переносом.
Локальная и продовая коллекции сверены по ID и содержимому.

Полная выгрузка `2026-10-31`: шесть слоёв, 54 файла, 1 506 387 записей.
`/dump/latest` переключён на эту версию; прежние версии сохранены.
Кэш содержимого сброшен штатной ручкой, `/data` обновлена принудительной
ревалидацией. Приложение отвечает `ready`, BUILD_ID совпадает с активным релизом.

Через публичные HTTPS-адреса с сервера проверены SHA-256 всех 14 файлов певческих
слоёв, страницы чтений Пасхи и Пятидесятницы, сохранённый редирект текста,
новости 6.3/6.4, `/about` и RSS. С рабочей машины проверены `/data`, `/license`
и манифест; полное скачивание большого файла прервалось по сетевому таймауту,
поэтому контрольные суммы проверялись с сервера. Это техническая проверка
выкладки; содержательная ручная проверка остаётся владельцу.
