## Источники и пределы сверки

Основной источник — [Типикон, гл.50](https://azbyka.ru/otechnik/Pravoslavnoe_Bogosluzhenie/tipikon/50),
издание Издательского Совета РПЦ, Москва, 2002. Общие правила — главы
[2](https://azbyka.ru/otechnik/Pravoslavnoe_Bogosluzhenie/tipikon/2),
[9](https://azbyka.ru/otechnik/Pravoslavnoe_Bogosluzhenie/tipikon/9),
[10](https://azbyka.ru/otechnik/Pravoslavnoe_Bogosluzhenie/tipikon/10),
[35](https://azbyka.ru/otechnik/Pravoslavnoe_Bogosluzhenie/tipikon/35).
Заупокойная суббота — также [гл.49, мясопустная суббота](https://azbyka.ru/otechnik/Pravoslavnoe_Bogosluzhenie/tipikon/49).
Рядовые будничные зачала, которые гл.50 не перечисляет полностью, сверены по
таблицам [богослужебного Апостола](https://azbyka.ru/otechnik/Pravoslavnoe_Bogosluzhenie/apostol-bogosluzhebnyj-grazhdanskim-shriftom-s-udarenijami/)
и [Евангелия](https://azbyka.ru/otechnik/Pravoslavnoe_Bogosluzhenie/evangelie-bogosluzhebnoe-grazhdanskim-shriftom-s-udarenijami/).
Состав паремий уточнён по соответствующим последованиям Цветной Триоди.

В JSON сохранены URL, SHA256 источников, номера абзацев и выдержки, обосновывающие
лакуны. `P…` — порядковый номер абзаца `<p>` внутри `<main>` HTML главы, а не страница
печатной книги. Гл.50 проверена по текущей сетевой публикации; остальные главы и
богослужебные книги — по локальному источниковому корпусу `typikon-rules/raw`.

Сверены принадлежность чтения дню и месту службы, книги и номера зачал, явно
названные слова и отдельные начала произведений. Каждое из 393 имеющихся назначений
получило категорию проверки. **Это не построчная текстологическая сверка всех
произведений и не проверка всех совпадений с Минеей.** Для 33 тематических
назначений отдельно подтверждены применимость существующего текста, готовность,
выбор статий и полнота вывода. Историческая атрибуция и тождество редакций этим
не устанавливаются.

## Расхождения имеющихся назначений

**Все святые — прежнее замечание снято.** На самом воскресенье сохраняется
Учительное Евангелие, слово22, двумя статиями: толкование праздничного Евангелия
Мф.10:32. По уточнению владельца последовательное чтение Златоуста на Матфея
с беседы13 начинается с понедельника после недели Всех святых, а не на её утрене.
Прежняя трактовка гл.50 P1368 как требования заменить воскресное чтение была
ошибочной. Замена книги и связанная с ней переделка статий исключены из очереди;
снятый вывод сохранён в JSON отдельно от действующих замечаний и исправлений.

**Преполовение — исправлено.** Первое чтение целиком следует источнику:
Мих.4 → Мих.6 → заключительные фразы Мих.5. Восстановлены частичные стихи,
обращение «людие Мои, помяните» и богослужебная редакция заключения. Второе
чтение имеет порядок Ис.55 → Ис.12:3–4 → Ис.55, включая частичные55:2,3,6
и литургические вводные/связующие фразы. Третье — Притч.9:1–11. Вместо пяти
самостоятельно показываемых фрагментов назначены три цельных текста.
[Источник](https://azbyka.ru/otechnik/Pravoslavnoe_Bogosluzhenie/sluzhby-chetvertoj-sedmitsy-po-pashe/4).

**Вознесение — исправлено.** Первое чтение заканчивается внутри Ис.2:3
на «и пойдем по нему». Второе объединяет Ис.62:10–12;63:1–3а,7–9; после
«от язык несть муж со Мною» сразу следует воспоминание милости Господней,
без непрочитываемого продолжения63:3 и стихов4–6. Третье начинается частью
Зах.14:1, далее часть14:4 до указания на восток, затем14:8–11. Разделение
Елеонской горы из второй половины14:4 не читается. Вместо четырёх фрагментов
назначены три цельных текста.
[Источник](https://azbyka.ru/otechnik/Pravoslavnoe_Bogosluzhenie/sluzhby-shestoj-sedmitsy-po-pashe/5).

Составные паремии являются богослужебной редакцией: часть фраз не совпадает
дословно с цельными стихами Елизаветинской Библии, а простая сборка ranges
ещё и сортирует их по канону. Поэтому для этих шести назначений хранится
точный текст Триоди в `liturgicalText`; `ranges` — параллельные ссылки,
а не инструкция восстановления тела. В API `verses` пуст, тело находится
в `liturgicalText.content`; сайт показывает именно его, с источником и
явной языковой подстановкой. Другие языки этих редакций пока не подготовлены.
Старые каталожные документы и полные библейские стихи сохранены.

Три паремии Пятидесятницы по книгам/началам соответствуют гл.50 P1185–1188;
это не удостоверяет каждую букву литургической редакции. Закрытые замечания
о Преполовении/Вознесении сохранены отдельно в `resolvedDiscrepancies` и
не увеличивают счёт23 исправленных мест первоначального перечня.

## Что пока нельзя исправлять автоматически

Частные календарные сценарии вынесены в [отложенную очередь из семи кейсов](triodion-special-cases.md).
Общие назначения уже проверены; эти сценарии сейчас не включаются в новый проход.

1. **Номера в источнике.** В гл.50 P1112 утреннее Евангелие Отцов названо Ин.67,
   но начало соответствует Ин.66; база и таблица богослужебного Евангелия дают66.
   В P853 субботы пятой седмицы Деян36, но начало соответствует37; база даёт37.
   В гл.49 P162 заупокойное Евангелие имеет номер17, а в богослужебном Евангелии16.
   Сохранить тексты, проверить печатный оригинал, не подгонять базу под один номер.
2. **Пятидесятница, толкование после кафизм — локальная валидация пройдена.**
   Назначено наше Учительное Евангелие21, один готовый текст в двух статиях:
   после первой кафизмы Ин.7:37–39 с толкованием, после второй — Ин.7:40–52,
   8:12 и заключительное поучение. Граница — существующий маркер `[Среда:]`.
   Реальный показ HTML совпал с каждой выбранной частью целиком, без пропусков
   и повторов; API передаёт тот же текст с селекторами1/2. Текст, его номер,
   деление и назначения не изменялись. Историческая реконструкция нумерации
   «слово8» не является результатом этой локальной проверки и не служит
   основанием менять корректно назначенное поучение.
   [Результат проверки](audits/pentecost-local-validation.json).
3. **Пролог.** `calcDay.ts` добавляет календарный `song6` перед триодным.
   Для всех 57 дат цикла2026 в соответствующем неподвижном дне есть хотя бы один
   готовый текст. Поэтому пустой `song6` шаблона сам по себе не является пропуском
   Пролога. На самостоятельных страницах шаблонов отсылка к календарю непоследовательна.
4. **Светлая седмица.** После6-й песни гл.50 P251–253 указывает чтение, но не
   называет отдельного произведения. Не считать это доказательством необходимости
   второй беседы Златоуста каждый день: календарное чтение уже может заполнять место.
5. **Кириопасха.** Дополнительное слово Григория в пасхальном `song6` имеет условие
   лишь в описании. Нужна отдельная проверка его показа по датам; это не обязательное
   чтение каждой Пасхи и не недостающий текст.
6. **Редакторский подбор.** 80 назначений за трапезой и из Толкового Апостола имеют
   содержательные основания, но их конкретные номера не предписаны гл.50.
   33 тематических назначения локально провалидированы по нашим текстам;
   это не утверждение о буквальном тождестве исторических редакций.
   Все сочетания с Минеей/храмом/Благовещением
   требуют самостоятельной проверки калькулятора.

Все скрипты работают без записи в базу. Второй автоматически сравнивает основные
зачала, проверяет полноту сетки и собирает категории назначений. Редакторские
заключения в `rules.json` датированы этим снимком: после исправлений их нужно
пересмотреть, они не являются автоматическим детектором всех возможных ошибок.
Технический отчёт повторного запуска не заменяет редакторские выводы: при смене
хеша требуется заново проверить содержание текста. Тела и HTML находятся только
во временном каталоге; сохраняемый отчёт содержит метаданные и короткие выдержки.
Исходная общая матрица `release-6.4-days.csv` обновлена только для Цветной Триоди;
70 дней Постной остаются `not-reviewed` в отношении этой источниковой сверки.

124 сравнения зачал (123 основных и Евангелие пасхальной вечерни), отсутствие пропущенных номеров бесед1–88,
защита от повторного дня, согласованность обеих CSV и ссылок отчёта;
`tsc --noEmit` завершился успешно.
