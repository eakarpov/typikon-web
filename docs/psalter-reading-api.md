# Чтение Псалтири

`GET /api/v2/posledovanie?key=psaltir-before&lang=cu` — начальный чин.
`GET /api/v2/posledovanie?key=psaltir-after&lang=cu` — конечный чин.

Оба возвращают обычные `rows` последования. Доступны книжные начертания `lang=cu` и `lang=cu_gr`; ответ сохраняет выбранный язык. Рубрики отделены от произносимого текста, повторения сохраняются в `repeatCount`. Источник: https://azbyka.ru/molitvoslov/psaltir-po-kafizmam.html. Версионированный снимок рядов находится в `src/lib/molitvoslov/psalter-book.json`; это старинные богослужебные тексты, допускаемые политикой LICENSE-CORPUS.md.

`GET /api/v2/prayer-text?place=psalter-1|psalter-2|psalter-3` сохраняет выбор групп из аккаунта. На первых двух славах текст содержит одно место под список; имя духовника остаётся «имярек». Поле `italic` содержит фразы для курсива, в частности «роди́телей мои́х». На третьей славе используется одна общая молитва «Помяни, Господи, рабов Твоих», объединяющая выбранные имена. `mode: none` по-прежнему возвращает пустой список.

Период приложения — локальный календарь, одна кафизма в день, включительные даты, полные круги по 20 дней с выбранной стартовой кафизмой. Чины появляются в первый и последний день каждого такого круга. Это не меняет серверные настройки поминовений и утренние молитвы.
