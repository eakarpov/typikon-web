# Уставные чтения

**[typikon.info](https://www.typikon.info)** — корпус церковнославянских текстов, которые Типикон
назначает к чтению за богослужением, и сайт, который показывает, что читается в данный день и
почему.

Корпус набран с печатных изданий: Пролог, Толковый апостол, Торжественник, Златоустник,
отцы-аскеты, жития, Библия в нескольких изданиях. Тексты размечены по зачалам, привязаны к дням
церковного года, снабжены ударениями и связаны со святцами, храмами и местами. Правила устава
разбираются отдельным движком, и сайт показывает не только результат, но и правило, по которому
он получен.

## Для кого и что здесь есть

**Читателю.**
- [Календарь](https://www.typikon.info/calendar) — чтения дня по календарю, Триоди и месяцеслову.
- Страница чтения с настройкой шрифта, размера и интервала; чтение без сети после установки сайта
  как приложения.
- [Библия](https://www.typikon.info/bible) — параллельное чтение изданий: церковнославянского,
  греческого, латинского, румынских, грузинского, английского, китайского, чувашских.
- [Святые](https://www.typikon.info/saints) с досье, [именины](https://www.typikon.info/imeniny),
  [трапеза по Типикону](https://www.typikon.info/trapeza) с основанием из книги.
- Личное (после входа): страница «Сегодня» с местом, где остановился в чтении, избранное,
  заметки, помянник с поминальными днями.
- Подписка на календарь (`/calendar.ics`), [новости](https://www.typikon.info/news) и RSS,
  Telegram-канал [@blagoslovie](https://t.me/blagoslovie), приложение для Android.

**Уставщику и клиросу.**
- [Устав](https://www.typikon.info/ustav) — последование службы, собранное по Типикону, рядом с
  правилами, которые его так сложили.
- Песнопения, каноны, акафисты, [подобны](https://www.typikon.info/podobny),
  [зачины](https://www.typikon.info/incipits), напевы с нотами и прослушиванием.

**Приходу.**
- Расписание богослужений: проект месяца, правки, лист на стенд, подписной календарь.
- [Виджет чтений](https://www.typikon.info/widget) для приходского сайта.
- Приём записок через помянник.
- Каталог [храмов и престолов](https://www.typikon.info/temples).

**Наборщику.**
- [Набор](https://www.typikon.info/nabor) — перекодировка старых кодировок (UCS, HIP) в юникод и
  разбор по знакам.
- [Ударения](https://www.typikon.info/accents), словарь, перевод гражданки в церковнославянское
  написание, [разбор набранного текста](https://www.typikon.info/razbor).

**Исследователю и разработчику.**
- [Хронология](https://www.typikon.info/chronology) — перевод дат между календарями.
- [Места](https://www.typikon.info/places) Писания и богослужения на карте.
- [Свод цитируемости](https://www.typikon.info/otzvuki): какие стихи Писания и как часто звучат
  за службой.
- [Публичный API](https://www.typikon.info/api) (v2, OpenAPI).
- [Выгрузка корпуса](https://www.typikon.info/data) по слоям, с версиями и DOI.

## Запуск у себя

Нужны Node 22 и MongoDB с копией базы. Без базы сайт не соберётся: карта сайта и календарная
лента пререндерятся из неё.

```bash
npm ci
npm run dev
```

Окружение разработки читается из `.env.development`; минимально нужны `MONGODB_URI` и
`SESSION_SECRET`. Остальные переменные включают отдельные разделы — список в
[ARCHITECTURE.md](ARCHITECTURE.md#окружение). Разделы песнопений и устава требуют файла корпуса
и службы из соседнего репозитория typikon-rules; без них они отвечают пусто, остальной сайт
работает.

Проверки:

```bash
npm test
npm run typecheck
npm run lint
```
