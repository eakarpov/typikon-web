# Шрифты мобильного чтения

Каталог `catalog.json` версии 1 содержит группы языков/письменностей, встроенные шрифты и загружаемые OTF. Идентификаторы групп и шрифтов стабильны. Новая версия файла получает новое имя с хешем и новый SHA-256; старые опубликованные файлы сохраняются для уже установленных клиентов.

Monomakh и Old Standard встроены в APK. Дополнительные файлы загружаются только при выборе, проверяются по размеру и SHA-256 и сохраняются для офлайн-чтения.

Hirmos представлен совместимым Unicode-преемником Ponomar. Ostrog UCS в каталог не включён. Файлы Ponomar, Pochaevsk и Fedorovsk взяты без изменений из репозиториев авторов; точные ревизии и полный текст SIL OFL указаны в каталоге. Лицензии также лежат рядом отдельными файлами.

Новая группа: `id`, `label`, `defaultFont`, `baseFamily`, `fonts` (ID шрифтов), `languages` (коды изданий). Новое загружаемое начертание: `id`, `label`, `path` (только имя OTF/TTF в этом каталоге), `size`, `sha256`, `license`, `licenseText`, `source`. Приложение получает список динамически; чтение языка может выбрать группу по коду языка. У Monomakh остаётся роль запасного шрифта для непокрытых ЦС-знаков.
