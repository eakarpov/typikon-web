# Шрифты

Все файлы здесь — в woff2: то же содержимое, что в исходных TTF и OTF, упакованное
вдвое плотнее (1 971 КБ → 853 КБ на набор). Пересборка — `npm run fonts:woff2`;
исходники в хранилище не лежат, они берутся из перечисленных ниже источников.

Сжатие, а не обрезка: сабсеттинг дал бы больше, но для церковнославянского он
опасен — выносные и уставные начертания легко не попасть в набор, а обнаружится
это на чужом тексте. Перевод формата вдобавок прямо разрешён OFL и не требует
переименования, тогда как обрезка — уже переделка.

## Основной текст сайта

- **Old Standard** (Regular, Bold, Italic, BoldItalic) — © Алексей Крюков,
  SIL Open Font License 1.1. Гражданский шрифт с засечками; им набрано всё,
  кроме церковнославянских текстов.

## Церковнославянские

Читатель выбирает любой из них в настройках чтения; по умолчанию — Мономах.
Все под SIL Open Font License 1.1 (текст — в `licenses/OFL-1.1.txt`).

| шрифт | источник | чем взят |
|---|---|---|
| **Monomakh** | [slavonic/Monomakh](https://github.com/slavonic/Monomakh) | по составу знаков полнее прочих: все 32 выносные буквы, все 9 уставных начертаний, 57 церковнославянских букв — отсюда и умолчание |
| **Ponomar** | [slavonic/Ponomar](https://github.com/slavonic/Ponomar) | современный синодальный набор; 781 знак, 29 выносных из 32 |
| **Triodion** | [slavonic/Triodion](https://github.com/slavonic/Triodion) | гарнитура патриархийных репринтов Триодей, Часослова, Типикона |
| **Fedorovsk** | [slavonic/Fedorovsk](https://github.com/slavonic/Fedorovsk) | допечатный извод, по шрифту Ивана Фёдорова |

Числа покрытия сняты нашим же разбором шрифтового файла (`/nabor/font`), а не
взяты из описаний. Им же отвергнут Acathist: 12 выносных букв из 32 — для
основного текста этого мало.
